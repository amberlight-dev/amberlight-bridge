# Security

Amberlight Bridge reads files on your Mac, runs a local HTTP server and can bring windows to the front and type into them. If you find a way to abuse any of that, please tell us privately first.

Email **hello@amberlight.dev** with the subject "Security". Include what you found, how to reproduce it and the Bridge version (menu bar → Diagnostics → About …). We answer within a few working days and credit you in the release notes if you like.

Please don't open a public issue for security problems.
